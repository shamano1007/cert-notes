`AIリーダー.md` を更新したので、HTML を再生成してください。

追加の指示: $ARGUMENTS

## 手順

1. **内容チェック** — 今回の差分に事実誤認・記述の不整合・書式崩れがないか確認する。
   問題があれば指摘し、修正してよいか判断を仰ぐ（軽微な誤字は直してよい）。

2. **書式チェック** — `CLAUDE.md` の「AIリーダー.md の書式ルール」に反する記述がないか確認する。
   特に**表（`|` 記法）とコードブロックは未対応**なので、追加されていたら知らせること。

3. **ビルド** — `cd html && python3 build.py`

4. **検算** — 生成物が Markdown と一致しているか数える。
   ```bash
   grep -c '^## ' AIリーダー.md          # 用語数（+1 が目次ぶん。目次を消していれば一致）
   grep -c '^# 第' AIリーダー.md          # 章数
   grep -c 'class="term"' html/AIリーダー.html
   grep -c 'class="chapter"' html/AIリーダー.html
   ```
   あわせて未変換の記法が残っていないか確認する（`AIリーダー.html` に `**` や `<p>- ` が出ていないこと）。

5. **表示確認** — `CLAUDE.md` の「表示確認の方法」に従い、PC とスマホ幅（iframe で 375px）の
   スクリーンショットを撮って崩れがないか目視する。

6. **報告** — 変更点、用語数・章数、確認結果を簡潔にまとめる。
   数が合わない・変換漏れがある場合は、取り繕わずそのまま報告すること。

## やらないこと

- `html/AIリーダー.html` を直接編集しない（自動生成物なので次回ビルドで消える）
- 左メニューの自動スクロール（`scrollIntoView`）を復活させない（理由は `CLAUDE.md` 参照）
